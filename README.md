# ⏳ Life Expiry

> *"Everything eventually runs out — remembered here."*

**Life Expiry** is a beautiful, feature-rich web application designed to track anything that expires: food, medicine, warranties, subscriptions, cosmetics, documents, and more. Built to be fast, private, and installable on any device.

## 📖 The Story

Hi, I'm **Hadi Rasooli**. 

I built Life Expiry because I was tired of finding expired milk in the fridge, forgetting when my car warranty ended, and losing track of monthly subscriptions. I wanted something that wasn't just a boring list, but a beautiful, personal dashboard that felt like a native app. 

I also wanted it to respect different cultures and languages, which is why I integrated multiple calendar systems and full RTL (Persian) support. As an AI enthusiast and builder, I use tools like [Prompted](https://www.prmpted.com/?ref=hadi_1_referral) to accelerate my development workflow, and I built this app from the ground up to solve a real problem in my daily life.

## ✨ Features

* **Multi-Tab Interface:** Clean, mobile-friendly UI with bottom navigation.
* **Multi-Language:** Full English and Persian (RTL) support.
* **4 Calendar Systems:** Gregorian, Persian (Jalali), Islamic, and Chinese.
* **3 Beautiful Themes:** Morning Dew (Light), Midnight Velvet (Dark), and Golden Blush (Luxe).
* **Cloud Sync:** Real-time data synchronization across devices using Firebase.
* **PWA Ready:** Installable on desktop and mobile, with offline support.
* **Smart Tracking:** Recurring items, quantities, custom locations, and tags.
* **Layouts:** Switch between a compact accordion view and a detailed grid.
* **Data Management:** Archive items, bulk actions, CSV export, and JSON backup/restore.
* **Statistics:** Visual charts of your expiring items.

## 🛠️ Tech Stack
* **Frontend:** Vanilla HTML, CSS, JavaScript (No heavy frameworks).
* **Backend / Database:** Firebase Firestore (for Cloud Sync).
* **PWA:** Service Worker and Web Manifest.
